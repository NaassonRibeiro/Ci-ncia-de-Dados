# Ciência de Dados com Python e Google Colab

Este repositório contém exemplos práticos utilizando Python no Google Colaboratory (Colab) para manipulação e visualização de dados.

## Arquivos

### `atividade.ipynb`

Notebook desenvolvido no Google Colab contendo exemplos de:

- Criação de séries com Pandas
- Manipulação de tabelas utilizando DataFrames
- Operações com matrizes utilizando NumPy
- Geração de gráficos com Matplotlib
- Visualização de dados em Python

O notebook foi estruturado em células de código e texto para facilitar a execução e interpretação dos resultados.

---

### `conjunto-dados.csv`

Arquivo CSV utilizado como exemplo de base de dados para leitura e manipulação com a biblioteca Pandas.

O arquivo demonstra como importar dados externos para análise em ambientes Python e Google Colab.

---

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

---

## Objetivo

Demonstrar conceitos introdutórios de análise e manipulação de dados utilizando ferramentas amplamente empregadas em Ciência de Dados.
